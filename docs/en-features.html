User Authentication

Implemented

Secure registration and login with email/password + Google OAuth

Features

  • ✓ Email/password registration with bcrypt hashing (10 rounds)
  • ✓ Google OAuth2 token verification via OAuth2Client
  • ✓ JWT access/refresh token pair (HS256)
  • ✓ httpOnly, secure cookies for token storage
  • ✓ Device-based session management (unique userId + userAgent)
  • ✓ Auth audit trail (AuthLog with type, IP, user agent)
  • ✓ Silent token refresh via proxy layer

Interactive Family Tree

Implemented

Dynamic, zoomable family-tree canvas with auto-layout and drag-and-drop
