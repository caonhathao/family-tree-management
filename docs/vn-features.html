Xác Thực Người Dùng

Đã Triển Khai

Đăng ký và đăng nhập an toàn bằng email/mật khẩu + Google OAuth

Tính Năng

  • ✓ Đăng ký email/mật khẩu với mã hóa bcrypt (10 rounds)
  • ✓ Xác minh token Google OAuth2 qua OAuth2Client
  • ✓ Cặp token JWT access/refresh (HS256)
  • ✓ Cookie httpOnly, secure để lưu token
  • ✓ Quản lý phiên bản theo thiết bị (userId + userAgent độc nhất)
  • ✓ Nhật ký xác thực (AuthLog với loại, IP, user agent)
  • ✓ Làm mới token im lặng qua lớp proxy

Công Nghệ Sử Dụng

JWT Passport.js bcrypt Google OAuth jose

Proxy Middleware: src/proxy.ts

Đường Dẫn

Gia Phả Động

Đã Triển Khai

Cây gia phả tương tác, có thể thu phóng với bố cục tự động và kéo thả

Tính Năng

  • ✓ Trực quan hóa React Flow với thành phần FamilyMemberNode tùy chỉnh
  • ✓ Thuật toán bố cục tự động Dagre.js (tight-tree layout)
  • ✓ Kéo thả vị trí thành viên với lưu bố cục canvas
  • ✓ Hồ sơ thành viên (tiểu sử, ngày quan trọng, thế hệ, giới tính)
  • ✓ Quản lý quan hệ (PARENT / SPOUSE / CHILD)
  • ✓ Đồng bộ dựa trên sự khác biệt (Mẫu Draft/Origin với lodash.isequal)
  • ✓ Đồng bộ toàn bộ cây qua Prisma $transaction
  • ✓ Thực thi vai trò (chỉ OWNER và EDITOR có thể sửa đổi)

Công Nghệ Sử Dụng

React Flow (@xyflow/react) Dagre.js Redux Toolkit lodash.isequal

Nhóm Gia Đình

Đã Triển Khai

Tạo nhóm, mời thành viên qua liên kết token, quản lý vai trò

Tính Năng

  • ✓ Tạo và quản lý nhóm gia đình
  • ✓ Truy cập dựa trên vai trò: OWNER / EDITOR / VIEWER
  • ✓ Hệ thống mời với token hết hạn 24 giờ (base64-encoded)
  • ✓ Chuyển quyền lãnh đạo (chỉ OWNER)
  • ✓ Xóa thành viên bởi chủ nhóm
  • ✓ Công việc tự động dọn dẹp lời mời (hàng ngày lúc nửa đêm)
